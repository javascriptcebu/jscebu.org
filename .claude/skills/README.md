# Skills used on this repo

## Impeccable (vendored here)

The design skills in this folder come from [pbakaus/impeccable](https://github.com/pbakaus/impeccable).
- License: Apache-2.0. See `LICENSE-impeccable` and `NOTICE-impeccable.md`.
- Copied unmodified on 2026-10-28, from the version installed on 2026-04-06 with the `skills` CLI.
- These are the exact versions the site was designed with.

The skills: adapt, animate, arrange, audit, bolder, clarify, colorize, critique, delight, distill, extract, frontend-design, harden, normalize, onboard, optimize, overdrive, polish, quieter, teach-impeccable, typeset.

**Before any design work, read `/.impeccable.md`.** It holds the project's design context, so you don't need to run `teach-impeccable`.

## Superpowers (enabled as a plugin)

The planning and delivery skills (brainstorming, writing-plans, executing-plans, subagent-driven-development, test-driven-development, requesting-code-review, finishing-a-development-branch) come from the [superpowers](https://github.com/obra/superpowers) plugin (MIT).
- `.claude/settings.json` enables it from the official marketplace, as `superpowers@claude-plugins-official`.
- It isn't copied here, because its scripts locate themselves by their installed path.
